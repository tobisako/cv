Jev とは ABOUT

Jev は、TypeSafe AI が 2026 年に公開した意思決定モデルです。入力は会話履歴ではなく、プログラムが渡す state（状況）と、型のついた questions（判定項目）です。出力は文章ではなく、選択の結果・スコア・真である確率で、コードはその値で分岐します。

ChatGPT 系は、トークンを順に生成する対話・作文のモデルです。Jev は、同じ state に対する複数の判定をまとめて返し、その値をソフトウェアがそのまま使います。公式ブログはこれを「unstructured state in, typed probabilistic decisions out」と書いています。[1] Jev を置くのは、エージェントやゲームループの中で次の一手を決める層です。

Vercel AI Gateway でのモデル名は typesafe-ai/jev で、チャット API ではなく、AI SDK の evaluate から呼び出します。[4] 判定の種類は3つで、AI SDK の型名では Choice（並べた候補から1つ選ぶ）、Score（段階で評価する）、Boolean（真である確率）です。Boolean は、TypeSafe AI のドキュメントでは Noul と呼ばれています。[2]

ゲームのコード安全装置・再生
  1. 画面は送らない。盤面・位置・先読みの結果を、JSON 形式の state にまとめる。
  2. 選択肢は、コードが「打てる」と確かめた手（合法手）だけにする。各選択肢には、選んだ場合にどうなるかを示す数字を添える。
  3. 物理・当たり判定・ライン消しには、ゲーム側のコードをそのまま使う。Jev が返すのは、どの分岐を選ぶかだけ。
  4. 答えが来ないとき、間に合わないとき、候補にない答えが返ってきたときは、コード自身の評価で1位の手を選んで進める。

STAGE 4

テトリス2D

元のゲーム: GABETROLL/Tetris3D の 2D モード（10×20）
録画2（効果音あり）。右上に Jev との送受信を示すハートビート、盤の上に「間に合わず」（Jev の答えが届く前にミノが固定された印）の表示を付けた版。13倍速で26ラインを消した。
録画1（効果音あり）。10秒ごとに速度を上げて、16倍速で67ラインのときゲームオーバー。
Jev に聞くことこのミノをどこに置くか（Choice）、選んだ位置と向きまでミノを動かしたら、そこで一気に落とすか（Boolean）、危険度（Score）。
コードが受け持つこと置き場所をすべてゲーム自身の関数で試し、置いたあとの盤を El-Tetris の重み（着地の高さ・消えるライン・穴などに掛ける係数）で採点する。1位との点差が15点以内の候補だけを、最大4つ渡す。1つしか残らなければ聞かずに置く。
繋ぐ前に確かめたこと候補からでたらめに選ぶ偽の橋でも、800個のミノを置くまでゲームオーバーにならなかった。
ゲームオーバーの理由16倍速では、Jev が答える約0.3秒のあいだにミノが約10段落ちる。応答の遅れだけを16倍速のときと同じにしたシミュレーションでも、約72ラインで同じように終わった。

テトリス3D

元のゲーム: GABETROLL/Tetris3D の 3D モード（4×4×20）
置き場所を比べる版（効果音あり）。右上に Jev に見せた p0〜p3 と、それぞれの落ちたあとの一番下の層。左上は速度と自然落下速度のスライダー。
生キー版（Jev にキーを直接選ばせる版）の最初の形。選んだキーを、次の答えが来るまで毎フレーム押し続ける。
生キー版の2つ目の形。1回の答えにつき、キーを1回だけ押す。
生キー版Jev に回転キー（ROTATE_CW_X など）を直接選ばせた。答えは21回すべて HARD（その場で落とす）だった。回転は一度も起きず、約15秒で終わり、消えた層は0。
置き場所を比べる版コードが、最大24姿勢×16位置の置き方それぞれについて、Game3D と同じ関数でミノを回して落とす。点が高い4通りの置き方について、ミノを落としたあとの井戸の層（after_layers）を Jev に見せる。井戸は、ミノを積む 4×4×20 の枠のこと。Jev は p0〜p3 から1つ選ぶ。
試験乱数を変えた5試合で、各60ミノについて、候補ごとの after_layers が、本物の盤でその候補どおりにミノを落として固定した結果と一致することを確かめた。
見た目井戸は20秒で1周する。ミノの回転は、1回につき0.5秒かけて見せる。層が消えると「+1」と出る。自然落下の間隔は、1段あたり2000msから始まり、レベルが上がるごとに100msずつ短くなる。

置き場所を比べる版の録画。101ミノのうち、Jev が配置を選んだのは92ミノ。消えたのは20層、到達したレベルは6。

分かったこと TIPS

キーを直接選ばせると、Jev は毎回 HARD を選んだ。回して落とした結果を並べて比べさせると、101個のミノのうち92個が、Jev の選んだ配置どおりに置かれた。
Jev の応答は0.3〜0.7秒。ゲームが速くなると、その間にミノや鳥が動く。先読み・安全装置・「間に合わず」の表示はコードの側に置いた。
フラッピーバードでは、はばたく・はばたかないの一方でしか生き残れない場面はコードが決め、どちらでも生き残れる場面だけ Jev に聞いた。テトリス2Dでは、1位の候補との点差が15点以内の置き場所だけを残し、1つしか残らなければコードが置いた。この絞り方なら、候補からでたらめに選んでも、800個のミノを置くまでゲームオーバーにならなかった。
